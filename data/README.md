# Audios de prueba

`Audios de prueba/` reúne 17 grabaciones para probar la diarización:

- `Hablantes por turnos/`: 13 diálogos y entrevistas con intervenciones sucesivas.
- `voces parecidas/`: 4 entrevistas para observar posibles confusiones entre voces.

La evaluación en `../evaluacion/` utiliza ocho archivos de estas carpetas,
identificados como Audio 1 a Audio 8 en `../evaluacion/anotaciones.json`.
Los otros archivos son casos de prueba disponibles para exploración; no forman
parte de las métricas guardadas. `../Tiempo_audios.xlsx` contiene las marcas
manuales de tiempo y la comparación con las salidas del sistema.

Los archivos de audio directamente en `data/` son los que ofrece el menú de
consola. Para probar un archivo de las subcarpetas, cárgalo desde la página web.
